# Boards are generated procedurally from the book's text

Each Scene's Board is generated procedurally from the Adventure Book's written description of that place, aiming to be faithful to it, instead of converting the PDF's map images into a grid. Converting printed maps (artistic, inconsistent scales, labels over walls) would never be reliable enough without a manual editor, and we chose not to build a map editor. The cost is that a Board may differ visually from the book's map while still matching its description.
