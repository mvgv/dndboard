# Private use: book content is never redistributed

dndboard is a private project played by the owner and their group with books they own. Only SRD 5.2 (CC-BY-4.0) may be bundled as-is. Everything else (the 2024 Player's Handbook, Monster Manual, Dungeon Master's Guide and the Adventure Books) enters only through the user importing their own PDFs, and the processed result is never published or distributed. Making the game public later would require revisiting this, since the processed Compendium and Adventures would then be derived copyrighted content.
