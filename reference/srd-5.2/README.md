# SRD 5.2 text

The `ruleset` skill reads the D&D 2024 rules from this folder. Put the System Reference Document 5.2 here as Markdown (one file per chapter is enough), converted from the official PDF published by Wizards of the Coast under CC-BY-4.0.

CC-BY-4.0 requires attribution: copy the attribution statement printed in the SRD 5.2's legal information into an `ATTRIBUTION.md` beside the text.

Only SRD content belongs here (ADR 0003): never Player's Handbook, Monster Manual or Adventure Book text.
